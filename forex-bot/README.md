# 🤖 بوت تداول الفوركس — Nomir Forex Bot

بوت مكتوب بلغة Python يقوم بـ:

1. **تتبّع الأسواق** — يجلب أسعار أزواج العملات والذهب بشكل دوري (Yahoo Finance مجاناً، أو OANDA، أو ملفات CSV).
2. **رصد فرص البيع والشراء** — استراتيجية اتباع الاتجاه مع تأكيد الزخم وإطار زمني أعلى، وتعطي كل فرصة **درجة قوة من 100** مع نقطة الدخول ووقف الخسارة والهدف.
3. **متابعة الأخبار الاقتصادية** — يقرأ التقويم الاقتصادي (NFP، الفائدة، التضخم CPI...) ويمتنع عن الدخول قبل/بعد الأخبار عالية التأثير، ويحلل عناوين الأخبار لمعرفة هل هي إيجابية أو سلبية لكل عملة.
4. **إدارة المخاطر** — حجم الصفقة يُحسب تلقائياً بحيث لا تخسر أكثر من 1% من الرصيد في الصفقة، مع حد خسارة يومي وحد لعدد الصفقات.
5. **التنفيذ** — محاكاة (Paper) افتراضياً، أو تنبيهات فقط، أو تنفيذ فعلي عبر OANDA.
6. **التنبيهات** — في الطرفية وعلى **تيليجرام**.
7. **الاختبار التاريخي (Backtest)** — لتقييم الاستراتيجية قبل المخاطرة بأي مال.

> ⚠️ **تنبيه مهم:** لا يوجد بوت يضمن ربحاً "محققاً". الفوركس عالي المخاطر وقد تخسر رأس مالك. ابدأ بوضع المحاكاة `paper` ثم الحساب التجريبي، واختبر تاريخياً، ولا تتداول بمال لا تتحمل خسارته. هذا البرنامج أداة تعليمية وليس نصيحة مالية.

## التثبيت

البوت لا يحتاج pandas ولا numpy — يعمل بمكتبة Python القياسية + مكتبة PyYAML الخفيفة فقط،
لذلك يعمل على الكمبيوتر وعلى هاتف أندرويد عبر **Termux** حتى في الهواتف القديمة.

```bash
cd forex-bot
pip install -r requirements.txt
```

### على هاتف أندرويد (Termux)

1. ثبّت Termux من https://github.com/termux/termux-app/releases (ملف `universal.apk`)
2. نفّذ:

```bash
pkg update -y && pkg upgrade -y
pkg install -y python git
pip install pyyaml
git clone -b ccr-63f5f8e9-r63nou https://github.com/wagja180/Nomir.git
cd Nomir/forex-bot
python -m forexbot news
```

3. للتشغيل المستمر: `termux-wake-lock` ثم `python -m forexbot run`،
   واجعل بطارية Termux "بدون قيود" من إعدادات الهاتف.

## الأوامر

```bash
python -m forexbot scan              # فحص كل الأزواج الآن وعرض الفرص
python -m forexbot news --hours 24   # الأحداث الاقتصادية القادمة واتجاه الأخبار
python -m forexbot backtest          # اختبار تاريخي لكل الأزواج
python -m forexbot backtest --symbol EURUSD --timeframe H4
python -m forexbot run               # تشغيل مستمر (يفحص كل 5 دقائق)
```

مثال على إشارة:

```
🔴 بيع EURUSD  | القوة 85/100
الدخول: 1.08974
وقف الخسارة: 1.09275 (30 نقطة)
جني الربح: 1.08372 (60 نقطة)
العائد/المخاطرة: 1:2.0
الحجم: 50,000 وحدة (0.50 لوت)
الأسباب:
  • الاتجاه العام هابط (EMA50/200)
  • الإطار الأعلى H4 يؤكد
  • تقاطع MACD
```

## كيف يقرر البوت؟

| الشرط | النقاط |
|---|---|
| الاتجاه: السعر و EMA50 فوق EMA200 (شراء) أو تحته (بيع) | 30 |
| الإطار الأعلى H4 يؤكد نفس الاتجاه | 20 |
| قوة الاتجاه ADX ≥ 20 | 15 |
| **زناد الدخول (إلزامي):** تقاطع MACD أو ارتداد RSI بعد تصحيح | 25 |
| RSI ليس في منطقة تشبع ضد الصفقة | 10 |
| اتجاه الأخبار يدعم/يعاكس | ±15 |

لا تُقبل الإشارة إلا إذا تجاوزت `min_score` (الافتراضي 70). وقف الخسارة = 1.5 × ATR، والهدف = ضعف المخاطرة.

**فلتر الأخبار:** إذا كان هناك خبر عالي التأثير (High) على إحدى عملتي الزوج خلال 30 دقيقة قبله أو بعده، يتجاهل البوت الزوج تماماً لتجنب التذبذب العنيف.

## الإعدادات (`config.yaml`)

- `mode`: `paper` محاكاة | `signals` تنبيهات فقط | `oanda_practice` حساب تجريبي | `oanda_live` حقيقي
- `symbols`: الأزواج المتابعة
- `timeframe`: الإطار الزمني (M15, M30, H1, H4, D1)
- `strategy`, `risk`, `news`: كل المعاملات قابلة للتعديل

## حدود يجب معرفتها

- بيانات Yahoo مجانية لكنها قد تتأخر وليست مناسبة للتداول السريع (سكالبينج).
- تحليل الأخبار يعتمد على كلمات مفتاحية إنجليزية — مفيد كمؤشر مساعد وليس فهماً كاملاً للخبر.
- في المحاكاة، إذا لمست الشمعة الوقف والهدف معاً يُحتسب الوقف (افتراض متحفّظ).
- نتائج الاختبار التاريخي لا تضمن نتائج المستقبل.
