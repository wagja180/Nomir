# مثال تطبيقي: سلسلة ريلز «عوالم مصغّرة»

ثماني أفكار ريلز مرّت على مهارات Nomir بالترتيب: `reel-hook-generator` ← `reel-scriptwriter` ← `caption-writer` ← `caption-linter` ← `hashtag-strategist` ← `content-calendar`.

النسخة الإنجليزية: [`examples/miniature-worlds`](../../examples/miniature-worlds/README.md)

## الافتراضات

لم تُشغَّل مهارة `ig-strategy` لهذا الحساب، فما يلي افتراضات عمل. استبدلها بالاستراتيجية الحقيقية قبل اعتماد التقويم.

```
المجال: عوالم مصغّرة مولَّدة بالذكاء الاصطناعي مخبّأة داخل أشياء يومية
الجمهور: من يوقف التمرير عند المشاهد الدافئة كثيرة التفاصيل ويحفظها ليعيد مشاهدتها
التميّز: كل منشور = شيء واحد، عالم مخبّأ واحد، وتفصيلة لا تُلاحظ إلا في المشاهدة الثانية

محاور المحتوى:
1. بيوت صغيرة - غرف وبيوت داخل شيء صغير واحد (فاكهة، علبة كبريت، جوزة)
2. تجمّعات صغيرة - قرى ومدن كاملة داخل شيء (زجاجة، ساعة جيب)
3. طبيعة خيالية - عوالم تنمو من الفطر والبلّور وجذوع الشجر

توزيع الصيغ: كل المحاور ← ريلز، مع كاروسيل تلخيصي كل أسبوعين
الوتيرة: 4 ريلز أسبوعياً (افتراض)
مقاييس النجاح: نسبة البقاء لأول 3 ثوانٍ، الحفظ نسبةً إلى الوصول، المشاركة نسبةً إلى الوصول
```

كل الريلز بصرية أولاً، مدتها 12-15 ثانية، بلا ظهور متحدث. الجملة «المنطوقة» تعليق صوتي اختياري، والنص على الشاشة يحمل الهوك عند كتم الصوت.

كل المنشورات صور مولَّدة بالذكاء الاصطناعي. فعّل وسم «محتوى بالذكاء الاصطناعي» في إنستغرام لكل منشور، ولا تكتب أن شيئاً منها صُنع يدوياً.
