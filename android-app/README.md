# 📱 تطبيق نومير فوركس — أندرويد

تطبيق أندرويد حقيقي بواجهة عربية لبوت الفوركس:

| الشاشة | ماذا تعرض |
|---|---|
| **الفرص** | إشارات البيع والشراء مع درجة القوة، الدخول، الوقف، الهدف، والأسباب + حالة كل زوج (صاعد/هابط، RSI، ADX) |
| **الأخبار** | التقويم الاقتصادي (الأخبار القوية والمتوسطة) + عناوين الأخبار مع اتجاه كل عملة |
| **الصفقات** | الحساب التجريبي: الرصيد، الصفقات المفتوحة وربحها العائم، السجل، نسبة الربح |
| **الإعدادات** | الأزواج، الإطار الزمني، قوة الإشارة، المخاطرة، التداول التلقائي، التنبيهات |

- يفحص السوق **في الخلفية** كل 15/30/60 دقيقة حتى لو كان التطبيق مغلقاً.
- **إشعارات** عند ظهور فرصة، وعند إغلاق صفقة، وقبل الأخبار القوية بساعة.
- يوقف الإشارات تلقائياً قبل وبعد الأخبار القوية بـ30 دقيقة.
- يتداول **بمال وهمي فقط** (حساب تجريبي) — لا يوجد ربح مضمون.

## التثبيت على الهاتف

1. افتح صفحة الإصدارات من هاتفك: https://github.com/wagja180/Nomir/releases/latest
2. نزّل ملف **NomirForex.apk**
3. افتحه ← اسمح بـ "التثبيت من مصادر غير معروفة" ← تثبيت
4. افتح التطبيق ← اسمح بالإشعارات
5. (مهم) الإعدادات ← التطبيقات ← نومير فوركس ← البطارية ← **بدون قيود**، حتى لا يوقف النظام الفحص في الخلفية.

كل تعديل على الكود يبني نسخة جديدة تلقائياً عبر GitHub Actions، ويمكن تثبيتها فوق القديمة.

## البناء بنفسك (اختياري)

افتح مجلد `android-app` في Android Studio واضغط Run، أو:

```bash
cd android-app
./gradlew assembleRelease
```
