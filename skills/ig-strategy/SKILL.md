# Instagram Account Strategy

The upstream skill the rest of the pack feeds into. Every hook, caption, and post should trace back to a content pillar defined here; if it doesn't, that's a sign the post doesn't belong, not a sign the strategy needs a sixth pillar.

## When to use
- Starting a new Instagram account from scratch.
- An existing account's content feels scattered, inconsistent, or isn't attracting the audience it wants.
- Before running `content-calendar` for the first time, or after a `performance-reviewer` session surfaces that the current pillars aren't working.

## Process

1. **Niche and positioning.** Get specific — not "fitness," but "strength training for new moms returning to lifting." Push back on anything too broad to differentiate.
2. **Audience persona.** One sentence: who they are, what they're struggling with, what they want instead. This should be specific enough that a post could be "obviously not for them."
3. **Differentiation.** One sentence on what this account does that competitors in the same niche don't (a specific angle, format, voice, or credential — not "better quality content").
4. **Content pillars.** 3-5 recurring themes, each tied to a reason it serves the audience persona. More than 5 dilutes; fewer than 3 gets repetitive. Each pillar should be nameable in a few words (e.g., "mistake breakdowns," "quick wins," "behind the scenes").
5. **Format mix.** Which pillars suit Reels vs. carousels vs. static posts vs. Stories, and roughly what ratio across a week/month.
6. **Posting cadence.** A realistic frequency given the user's production capacity — don't recommend daily posting to someone who can't sustain it; a sustainable 3x/week beats an abandoned daily plan.
7. **Success metrics.** 2-3 metrics that match the actual goal (follower growth vs. save rate vs. profile visits vs. link clicks) — not every account should optimize for the same number.

## Output format

```
Niche: [specific niche]
Audience: [one-sentence persona]
Differentiation: [one sentence]

Content pillars:
1. [name] - [why it serves the audience]
2. ...

Format mix: [pillar -> format(s)]
Cadence: [frequency, realistic to stated capacity]
Success metrics: [2-3 metrics tied to the actual goal]
```

## Guardrails
- Don't accept a vague niche or persona — ask one follow-up question rather than filling in generic placeholders.
- Don't recommend a cadence the user has already said they can't sustain; adjust pillars/scope instead of ignoring stated capacity.
- This is a living document, not a one-time output — note that it should be revisited after `performance-reviewer` finds a pillar underperforming.
