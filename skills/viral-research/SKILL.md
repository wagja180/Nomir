# Viral Research

Pattern extraction, not copying. The goal is a reusable structural insight ("this works because X"), not a knockoff of someone else's specific post.

## When to use
- The user shares a link, screenshot, transcript, or description of a post that's performing well (in their niche or a competitor's) and wants it broken down.
- The user asks what's trending or working right now in a given niche.
- Feeding into `reel-hook-generator`, `reel-scriptwriter`, or `trend-audio-finder` with a concrete pattern to riff on, rather than starting from nothing.

## Process

1. **Get the source material.** This skill analyzes what's given to it (a link fetched via a web tool, a pasted transcript/caption, a description of the post) — it does not have live access to Instagram's own trending feeds or algorithm data. If the user wants to find candidates to analyze, say so and use available search/fetch tools, or ask them to paste examples.
2. **Break down the structure**, not just "it's good":
   - Hook: which formula (see `reel-hook-generator`'s formula list) and why it grabbed attention in the first 1-3 seconds.
   - Pacing: cut frequency, how long each beat holds, where it speeds up/slows down.
   - Format: talking head, B-roll, text-overlay, carousel, voiceover-over-footage, etc.
   - Caption style: length, CTA, tone — does it do the work alone or lean on the video.
   - Audio: trending sound, original audio, voiceover, or silence-reliant (text-only).
   - Retention mechanism: what kept people watching past the hook (open loop, escalating stakes, list structure, payoff held to the end).
3. **Extract the transferable pattern** — the structural choice that would work on a different topic, separate from the specific content. State it as a reusable line: "Open on the result, hold the method until 10 seconds in, pay it off with a specific number."
4. **Adapt, don't clone.** Propose how this account's content (its pillars, from `ig-strategy`) could use the same structural pattern with its own specific content — never suggest replicating someone else's exact script, visuals, or claims.
5. Log the entry in swipe-file format (below) so it accumulates into a reusable reference over time.

## Output format

```
Source: [what was analyzed]
Hook formula: [name + why it worked]
Pacing: [notes]
Format: [notes]
Caption style: [notes]
Audio: [notes]
Retention mechanism: [notes]

Transferable pattern: [one reusable line]
Adaptation for this account: [specific idea using the account's own pillars/content]
```

## Guardrails
- Never suggest copying another creator's specific script, visuals, or verbatim phrasing — extract the structure, build new content from it.
- Don't claim access to live Instagram trend/algorithm data this skill doesn't have — work from what's actually provided or fetchable, and say so.
- If a post appears to be performing well due to something ethically or factually dubious (misleading claims, manipulated engagement), flag that rather than recommending it as a pattern to adopt.
