# Worked example: a miniature-worlds Reel series

Eight Reel ideas run through the Nomir pipeline: `reel-hook-generator` → `reel-scriptwriter` → `caption-writer` → `caption-linter` → `hashtag-strategist` → `content-calendar`.

## Assumptions

`ig-strategy` was not run for this account, so these are working assumptions. Replace them with the real strategy before treating the calendar as final.

```
Niche: AI-generated miniature worlds hidden inside everyday objects
Audience: people who stop scrolling for cozy, detailed, "look closer" visuals and save them to rewatch
Differentiation: every post is one object, one hidden world, one detail you only catch on the second watch

Content pillars:
1. Tiny homes - single rooms and houses inside one small object (fruit, matchbox, walnut)
2. Tiny settlements - whole villages and cities inside an object (bottle, pocket watch)
3. Fantasy nature - worlds that grow out of mushrooms, crystals, tree hollows

Format mix: all pillars -> Reels; one recap carousel per fortnight
Cadence: 4 Reels a week (assumed)
Success metrics: 3-second hold rate, saves per reach, shares per reach
```

All Reels are visual-first, 12-15 seconds, no talking head. The "spoken" hook is an optional voiceover; the on-screen text carries the hook with sound off.

Every post is AI-generated imagery. Turn on Instagram's AI label for each one, and do not caption any of them as hand-built.
